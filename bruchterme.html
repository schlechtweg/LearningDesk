Einfach erklärt

Einen Bruch wie 34 kennst du schon. Bei einem Bruchterm steht im Nenner (unten) eine Variable, zum Beispiel 5x oder x + 1x − 2.

Für x kannst du Zahlen einsetzen, aber nicht jede. Durch 0 darf man nämlich nicht teilen!

Die Definitionsmenge

Die Definitionsmenge D enthält alle Zahlen, die du einsetzen darfst. Verboten sind die Zahlen, bei denen der Nenner 0 wird.

So findest du sie: Setze den Nenner gleich 0 und löse nach x auf. Diese Zahlen schließt du aus.

Beispiel: 5x − 2  →  x − 2 = 0  →  x = 2

D = ℚ \ {2}

Lies: „D ist gleich ℚ ohne 2“. ℚ sind alle rationalen Zahlen, also alle Brüche und ganzen Zahlen.

Mehrere verbotene Zahlen

Steht im Nenner ein Produkt, wird er 0, sobald ein Faktor 0 ist.

1x·(x + 3)  →  x = 0 oder x = −3

D = ℚ \ {−3; 0}

Tipp: Nenner wie x2 − 9 zuerst mit der 3. binomischen Formel zerlegen: (x + 3)(x − 3). Verboten sind dann 3 und −3.

Ausprobieren: Wertetabelle

Wähle einen Bruchterm. Die rot markierten Felder zeigen, wo der Nenner 0 wird. Dort ist der Term nicht definiert.

Kürzen und Erweitern

Wie bei normalen Brüchen

Kürzen heißt: Zähler und Nenner durch dasselbe teilen. Erweitern heißt: Zähler und Nenner mit demselben malnehmen. Der Wert des Bruchs bleibt dabei gleich.

Die wichtigste Regel

Du darfst nur Faktoren kürzen, also Teile, die mit mal verbunden sind. Teile, die mit plus oder minus verbunden sind, darfst du nicht kürzen.

Merkspruch: „Aus Summen kürzen nur die Dummen.“

Richtig

6x29x = 2 · 3 · x · x3 · 3 · x = 2x3

Gemeinsame Faktoren: 3 und x. Die werden gekürzt.

3x + 63 = 3 · (x + 2)3 = x + 2

Erst ausklammern, dann ist die 3 ein Faktor und darf weg.

Falsch

x + 3x = 3  ✗

Das x oben ist mit + verbunden, also kein Faktor. Probe mit x = 1: 1 + 31 = 4, nicht 3.

x + 5x + 5… das geht hier zufällig, weil Zähler und Nenner gleich sind (= 1). Aber x + 5x + 2 kann man nicht kürzen.

Kürzen mit binomischen Formeln

Oft muss man Zähler oder Nenner erst in Faktoren zerlegen. Dabei helfen die binomischen Formeln:

x2 − 9x + 3 = (x + 3)(x − 3)x + 3 = x − 3

x2 + 4x + 4x + 2 = (x + 2)2x + 2 = x + 2

Jetzt ist (x + 3) bzw. (x + 2) eine ganze Klammer, also ein Faktor. Den darf man kürzen.

Erweitern

Erweitern brauchst du, um Bruchterme auf einen gemeinsamen Nenner zu bringen. Zähler und Nenner werden mit demselben Term malgenommen:

3x = 3 · 2x · 2 = 62x     5x = 5 · xx · x = 5xx2

Die vier Grundrechenarten

Rechnen mit Bruchtermen

Es gelten dieselben Regeln wie bei Zahlenbrüchen. Wenn du mit normalen Brüchen rechnen kannst, kannst du es auch hier.

Multiplizieren

Zähler mal Zähler, Nenner mal Nenner. Am besten vorher kürzen.

2x3 · 94x2 = 2x · 93 · 4x2 = 18x12x2 = 32x

Dividieren

Mit dem Kehrwert malnehmen. Den zweiten Bruch umdrehen und dann multiplizieren.

3x : 6x2 = 3x · x26 = 3x26x = x2

Addieren · gleicher Nenner

Zähler addieren, Nenner bleibt.

3x + 1 + 5x + 1 = 8x + 1

Beim Subtrahieren genauso, aber Klammern setzen, wenn der zweite Zähler eine Summe ist!

Addieren · verschiedene Nenner

Erst auf einen gemeinsamen Nenner erweitern (Hauptnenner), dann die Zähler addieren.

2x + 32x = 42x + 32x = 72x

Den Hauptnenner finden

  1. Zerlege alle Nenner in Faktoren, zum Beispiel 2x = 2 · x und x2 = x · x.
  2. Nimm jeden Faktor so oft, wie er höchstens in einem Nenner vorkommt.
  3. Beispiel: Nenner 2x und x2, also Hauptnenner 2 · x · x = 2x2.
  4. Haben die Nenner nichts gemeinsam, nimmst du einfach ihr Produkt: 1x + 1x + 1 = x + 1x(x + 1) + xx(x + 1) = 2x + 1x(x + 1)

Typische Fehler

  • 1x + 12 = 2x + 2 ist falsch. Nenner werden beim Addieren nie addiert.
  • Beim Subtrahieren die Klammer vergessen: 5x − 2 + xx = 5 − (2 + x)x = 3 − xx, nicht 7 + xx oder 3 + xx.
  • Beim Dividieren den ersten statt den zweiten Bruch umdrehen.
  • Die Definitionsmenge vergessen. Sie gilt auch für das Ergebnis, selbst wenn ein Faktor weggekürzt wurde.
