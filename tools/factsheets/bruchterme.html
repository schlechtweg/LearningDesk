Bruchterme

Factsheet
Ein Bruchterm hat eine Variable im Nenner, z. B. 5x oder x + 1x − 2. Man rechnet damit wie mit normalen Brüchen. Aber: Durch 0 darf man nicht teilen!

Definitionsmenge D

Alle Zahlen, die man einsetzen darf. Verboten sind die Zahlen, für die der Nenner 0 wird.

  1. Nenner gleich 0 setzen.
  2. Nach x auflösen.
  3. Diese Zahlen ausschließen.

5x − 2: x − 2 = 0 ⇒ x = 2, also D = ℚ \ {2}

1x(x + 3): D = ℚ \ {−3; 0} (ein Faktor = 0)

1x2 − 9 = 1(x+3)(x−3): D = ℚ \ {−3; 3}

Kürzen und Erweitern

Kürzen: Zähler und Nenner durch dasselbe teilen. Erweitern: mit demselben malnehmen. Der Wert bleibt gleich.

Nur Faktoren kürzen, keine Summanden! „Aus Summen kürzen nur die Dummen.“

6x29x = 2x3   3x + 63 = 3(x + 2)3 = x + 2

x2 − 9x + 3 = (x+3)(x−3)x + 3 = x − 3

Tipp: Erst ausklammern oder mit binomischen Formeln zerlegen, dann kürzen.

Rechenregeln

RechenartRegelBeispiel
MultiplizierenZähler mal Zähler, Nenner mal Nenner, dann kürzen2x3 · 94x2 = 18x12x2 = 32x
Dividierenmit dem Kehrwert des zweiten Bruchs malnehmen3x : 6x2 = 3x · x26 = x2
Addieren, gleicher NennerZähler addieren, Nenner bleibt3x + 1 + 5x + 1 = 8x + 1
Addieren, verschiedene Nennererst auf den Hauptnenner erweitern, dann Zähler addieren2x + 32x = 42x + 32x = 72x

Hauptnenner finden

  1. Alle Nenner in Faktoren zerlegen: 2x = 2·x, x2 = x·x
  2. Jeden Faktor so oft nehmen, wie er höchstens in einem Nenner vorkommt: 2·x·x = 2x2
  3. Nichts gemeinsam? Dann das Produkt: 1x + 1x+1 = 2x+1x(x+1)

Typische Fehler

  • x + 3x = 3 falsch: Das x oben ist ein Summand, kein Faktor.
  • Nenner addieren: 1x + 12 ≠ 2x + 2
  • Minus vor einem Bruch: Zähler in Klammern setzen, 5 − (2 + x)x
  • Beim Teilen den falschen Bruch umdrehen.
  • Die Definitionsmenge vergessen.
