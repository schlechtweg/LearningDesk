Binomische Formeln

Factsheet
Wenn man eine Klammer mit zwei Teilen (ein Binom) mit sich selbst malnimmt, entsteht immer dasselbe Muster. Mit den drei binomischen Formeln löst du solche Klammern blitzschnell auf, vorwärts und rückwärts.

Die drei Formeln

1. Formel (Plus)2. Formel (Minus)3. Formel (Plus-Minus)
(a + b)2 = a2 + 2ab + b2 (a − b)2 = a2 − 2ab + b2 (a + b)(a − b) = a2 − b2
(x + 3)2 = x2 + 6x + 9(x − 5)2 = x2 − 10x + 25(x + 4)(x − 4) = x2 − 16

Merkschema

  1. Erster Teil hoch 2: a2
  2. 2 · erster · zweiter: 2ab (Mittelglied, Vorzeichen wie in der Klammer)
  3. Zweiter Teil hoch 2: b2, immer mit Plus

Bei der 3. Formel heben sich +ab und −ab auf.

Warum? Das Flächenmodell

Ein Quadrat mit Seite a + b besteht aus a2, zwei Rechtecken ab und b2. Darum ist (a + b)2 = a2 + 2ab + b2.

Oder „jeder mit jedem“: (a+b)(a+b) = a2 + ab + ba + b2

Beispiel Schritt für Schritt

(2x + 5)2 mit a = 2x, b = 5:

  1. a2 = (2x)2 = 4x2
  2. 2ab = 2 · 2x · 5 = 20x
  3. b2 = 25

Ergebnis: 4x2 + 20x + 25

Rückwärts (faktorisieren)

  1. Suche zwei Quadrate: x2 und 9, also a = x, b = 3.
  2. Prüfe das Mittelglied: 2 · x · 3 = 6x.
  3. Vorzeichen entscheidet: x2 − 6x + 9 = (x − 3)2
  4. Kein Mittelglied, Minus dazwischen: 3. Formel, x2 − 9 = (x+3)(x−3)

Kopfrechen-Trick

  • 212 = (20 + 1)2 = 400 + 40 + 1 = 441
  • 492 = (50 − 1)2 = 2500 − 100 + 1 = 2401
  • 32 · 28 = (30 + 2)(30 − 2) = 900 − 4 = 896

Typische Fehler

  • (x + 3)2 = x2 + 9 falsch: Das Mittelglied 6x fehlt!
  • (x − 5)2 = … − 25 falsch: am Ende immer + 25.
  • (3x)2 = 3x2 falsch: richtig ist 9x2.
  • Die 2 im Mittelglied vergessen.
