Einfach erklärt

Eine Gleichung ist wie eine Waage im Gleichgewicht. Was du auf der einen Seite wegnimmst oder dazulegst, musst du auch auf der anderen Seite tun. Sonst kippt die Waage.

Ziel: Am Ende steht x allein auf einer Seite, zum Beispiel x = 5. Diese Zahl ist die Lösung.

Links liegen 3 Kisten mit unbekanntem Gewicht x und 5 kg, rechts 20 kg. Nimm auf beiden Seiten 5 kg weg: 3 Kisten wiegen 15 kg, also wiegt eine Kiste 5 kg.

Erlaubte Umformungen

Äquivalenzumformungen

  • Auf beiden Seiten dieselbe Zahl oder denselben Term addieren oder subtrahieren.
  • Beide Seiten mit derselben Zahl multiplizieren oder durch dieselbe Zahl dividieren, aber nie mit 0.

Man schreibt die Umformung rechts hinter einen senkrechten Strich:

3x + 5 = 20| −5
3x = 15| :3
x = 5
Fahrplan

So löst du jede lineare Gleichung

  1. Klammern auflösen und auf jeder Seite zusammenfassen.
  2. Alle x-Terme auf eine Seite bringen (zum Beispiel | −2x).
  3. Alle Zahlen auf die andere Seite bringen (zum Beispiel | +4).
  4. Durch die Zahl vor x teilen (zum Beispiel | :3).
  5. Probe: Lösung in die Ausgangsgleichung einsetzen. Beide Seiten müssen gleich sein.
2(x + 3) = x − 1Klammer auflösen
2x + 6 = x − 1| −x
x + 6 = −1| −6
x = −7
Probe: 2(−7 + 3) = −8 und −7 − 1 = −8 ✓

Sonderfälle

Manchmal verschwindet x ganz:

  • 0 = 5 ist falsch: keine Lösung, L = { }.
  • 0 = 0 ist immer wahr: jede Zahl ist Lösung, L = ℚ.

Typische Fehler

  • Nur eine Seite umgeformt. Jede Umformung gilt für beide Seiten!
  • Beim Subtrahieren das Vorzeichen falsch: Aus x + 6 = −1 wird x = −7, nicht 5.
  • Durch x geteilt: verboten, denn x könnte 0 sein.
  • Die Probe vergessen. Sie zeigt sofort, ob die Lösung stimmt.
Umformungs-Werkstatt

Forme selbst um

Gib eine Umformung ein, zum Beispiel -3, -2x oder :4. Sie wird auf beide Seiten angewendet. Löse die Gleichung so, dass x allein steht. Du kannst auch Umwege gehen. Mit „Rückgängig“ nimmst du einen Schritt zurück.

Trainer

Gleichungen lösen

Gib die Lösung ein, zum Beispiel x = 4, -7 oder 7/2. Unter „Lösung zeigen“ findest du den Rechenweg mit Probe.
